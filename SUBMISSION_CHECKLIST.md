# Submission Checklist

Before submitting:

- Extract the ZIP and keep the complete folder structure.
- Confirm Python 3.10 or later is installed.
- Double-click `run_windows.bat`.
- Double-click `run_collector_windows.bat` and confirm that it creates an Excel file in `output`.
- Open `output/job_role_finder_combined.xlsx` and confirm that it contains both `Job Role Catalogue` and `Jobs - Last 30 Days` sheets.
- Confirm that catalogue role titles are unique and the live sheet includes the application link or employer email column.
- Confirm that `http://127.0.0.1:5000` opens.
- Search for `Python` and test the filters.
- Search a public job feed while connected to the internet.
- Import `data/sample_import.csv` to demonstrate offline collection.
- Save the displayed rows and download the Excel workbook.
- Open one role and close its details window.
- Review `documentation/Job_Role_Finder_Project_Report.pdf`.
- Open `documentation/Job_Role_Finder_Presentation_Final.pptx`.
- Practise using `documentation/Demonstration_Script.md`.
- Submit the complete `Job_Role_Finder_Submission.zip` file.
- Create an empty GitHub repository and follow the commands in `README.md` if a repository link is required.

Do not upload or deploy the application online. Its working address is the local link `http://127.0.0.1:5000`.
